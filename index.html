Cara Install

Pasang dalam beberapa langkah

Muncul peringatan keamanan saat pertama membuka? Wajar—aplikasi di luar App Store / Microsoft Store. Ikuti langkah di bawah.

🍎 Cara install di Mac (Silicon & Intel)
  1. Buka file .dmg, lalu seret aplikasi ke folder Applications.
  2. Buka pertama kali: klik-kanan ikon app → Open → klik Open sekali lagi. (cukup sekali)
  3. Jika muncul “…is damaged”: buka Terminal, tempel baris ini lalu Enter, kemudian buka lagi (klik-kanan → Open):
    xattr -cr "/Applications/Fast Assistant Uploader.app"
🪟 Cara install di Windows 10 / 11
  1. Klik dua kali file setup.exe.
  2. Jika muncul “Windows protected your PC”: klik More info → Run anyway.
  3. Ikuti proses pemasangan sampai selesai, lalu buka aplikasinya.

🔒 Peringatan itu muncul karena aplikasi belum ditandatangani resmi—aman dijalankan. Butuh bantuan? chat WhatsApp.

FAQ

Pertanyaan yang sering ditanya

Satu lisensi untuk berapa perangkat?
Satu lisensi berlaku untuk satu perangkat (Windows atau Mac). Mau pindah perangkat? Chat kami.
Bagaimana cara mendapatkan kunci lisensinya?
Chat WhatsApp → pilih paket → bayar → buka aplikasi & kirim Device ID → kami kirim kunci → tempel di aplikasi, langsung aktif.
Apakah aman?
Aman. Aplikasi hanya membantu proses unggah ke akun FotoYu milikmu sendiri — tidak menyimpan data pribadi atau kata sandi di server kami.
Kenapa muncul peringatan "aplikasi tidak dikenal / rusak" saat install?
Wajar—aplikasi di luar App Store / Microsoft Store belum ditandatangani resmi. Ikuti panduan di bagian Cara Install. Aman dijalankan.
Bisa coba dulu sebelum beli?
Aplikasinya bisa diunduh gratis. Untuk mulai mengunggah dibutuhkan lisensi aktif—ingin mencoba dulu? Chat WhatsApp.
